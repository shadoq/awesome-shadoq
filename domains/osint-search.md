# OSINT and search

[Back to the index](../README.md)

## In short

Open-source intelligence means answering questions from public data. The skill is knowing which index holds the answer.

- **Internet-facing devices and leaks:** Shodan and LeakIX index exposed services; use them to audit your own infrastructure.
- **Images:** TinEye finds where an image appears and in which versions.
- **Frameworks:** the Polish extension of the OSINT Framework lists tools and registries by question type.
- **Maps and data:** historical maps (Arcanum), power plant data, economic indicators.
- **Search operators** still work and are underused.

Use these tools on your own assets or with permission.

## Data and dashboards

- [Global Integrated Power Tracker](https://globalenergymonitor.org/projects/global-integrated-power-tracker/tracker-map) - Global dataset and interactive map of power plants tracking the energy transition.
- [Arcanum Maps](https://maps.arcanum.com/en/) - Interactive viewer of historical 19th-century maps of Europe.
- [Cybermonit](https://cybermonit.com/) - Dashboard tracking CVE vulnerabilities, data leaks, ransomware and DDoS activity.
- [e-mapa.net](https://e-mapa.net/) - Free Polish map portal with plots, administrative borders, addresses and buildings.
- [gods-eye-view](https://github.com/bilawalsidhu/gods-eye-view) - Browser-based 3D globe that shows live open-source spatial data in a satellite-view style.
- [IP addresses of search engine spiders](http://iplists.com/) - Lists of IP addresses used by search engine crawlers, for verifying bot traffic.
- [situation-monitor](https://github.com/hipcityreg/situation-monitor) - Real-time dashboard tracking global news, markets and geopolitical events.
- [Trading Economics](https://pl.tradingeconomics.com/) - Economic indicators, historical data, charts and forecasts for 196 countries.

## OSINT

- [Otwarte Źródła](https://www.otwartezrodla.pl/) - Polish extension of the OSINT Framework: tools and data sources for open-source research.
- [TinEye](http://www.tineye.com/) - Reverse image search engine for finding where an image appears online.
- [GHunt](https://github.com/mxrch/GHunt) - Open-source tool for investigating Google accounts from an email address.
- [Robtex](http://www.robtex.com/) - Online DNS, IP and domain lookup tool for network research.
- [youtubevideofinder](https://github.com/TheTechRobo/youtubevideofinder) - Tool that searches web archives for lost or deleted YouTube videos.

## Search engines

- [LeakIX](https://leakix.net/) - Search engine indexing exposed services and data leaks across the internet for security research.
- [Shodan](https://www.shodan.io/) - Search engine for internet-connected devices, used in security research.
- [Google advanced operators guide (PL)](http://www.ittechnology.us/zaawansowane-operatory-google) - Polish guide to advanced Google search operators for finding better results.
- [You.com](https://you.com/home) - AI-powered web search APIs and consumer search app.
