# No-code and automation

[Back to the index](../README.md)

## In short

No-code tools are good at gluing systems together and bad at becoming the system. Use them where the logic is simple and the integrations are many.

- **Automation:** n8n (self-hostable), Pipedream and Kestra cover developer-friendly workflows; IFTTT and Huginn handle small personal triggers.
- **AI agent builders:** Flowise and Langflow let you draw LLM flows visually; good for prototypes, and you can move to code when they grow.
- **Builders:** Bubble for full apps, GrapesJS and craft.js when you need to embed a page editor inside your own product.
- **Watch for lock-in:** check export options and self-hosting before you build anything you cannot afford to lose.

**Where to start:** n8n with the self-hosted AI starter kit (see the self-hosting page) and a template collection.

## App and site builders

- [Bubble](https://bubble.io/) - No-code platform for building web and mobile apps with a visual editor and database.
- [craft.js](https://github.com/prevwong/craft.js) - Framework for building extensible drag-and-drop page editors in React.
- [GrapesJS](https://github.com/artf/grapesjs) - Open-source web builder framework for creating templates without coding.
- [blocks](https://github.com/blocks/blocks) - JSX-based page builder for creating websites without writing code.
- [brick-design](https://github.com/brick-design/brick-design) - Chinese-language low-code framework with drag-and-drop layout and visual configuration.
- [Framer](https://www.framer.com/) - Website builder and design tool with AI, hosting and CMS built in.
- [Mixo](https://www.mixo.io/) - AI website builder that creates small-business websites in minutes.
- [No-Code Tools PL](https://www.nocodetools.pl/) - Polish search directory of over 200 no-code productivity tools.
- [openchakra](https://github.com/premieroctet/openchakra) - Visual editor and code generator for React using Chakra UI.
- [React Bricks](https://github.com/ReactBricks) - Visual CMS and page-builder tools based on React components.
- [Shuffle](https://shuffle.dev/) - Visual editor for building websites faster with AI, aimed at developers and designers.
- [Softr](https://www.softr.io/) - No-code builder for client portals, internal tools and web apps.
- [Thunkable](https://thunkable.com/) - No-code builder for native iOS and Android apps with AI-assisted design.
- [Wegic](https://wegic.ai/) - AI website builder that acts as designer, developer and manager for a site.

## Workflow automation

- [huginn](https://github.com/huginn/huginn) - Self-hosted system for creating agents that monitor the web and act on your behalf.
- [IFTTT](https://ifttt.com/) - Automation service connecting many apps and devices through applets, without coding.
- [Kestra](https://kestra.io/) - Open-source declarative platform for building scalable automation and data workflows.
- [Pipedream](https://pipedream.com/) - Integration platform connecting APIs, databases and AI agents with managed auth.
- [autokitteh](https://github.com/autokitteh/autokitteh) - Durable workflow automation engine where workflows are written as code.
- [Latenode](https://latenode.com/) - Low-code workflow automation platform with built-in LLM nodes and many integrations.
- [n8n Templates 3000 spreadsheet](https://docs.google.com/spreadsheets/u/0/d/13_Gv7b6N7TgF-6vjopC50NBClp51DWf1KKxGnqsiVRg/htmlview) - Spreadsheet listing n8n workflow templates.
- [Templated](https://templated.io/) - API for generating images, videos and PDFs from templates.

## AI agent builders

- [Flowise](https://github.com/FlowiseAI/Flowise) - Open-source visual builder for AI agents and LLM flows.
- [Langflow](https://github.com/logspace-ai/langflow) - Visual builder for AI-powered agents and workflows, built on LangChain.
- [n8n AI workflow tutorial](https://docs.n8n.io/advanced-ai/intro-tutorial) - Tutorial on building an AI workflow in n8n.
- [PartyRock](https://partyrock.aws/) - Amazon no-code playground for building and sharing simple AI-powered apps in the browser.
