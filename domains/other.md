## Utilities

- [Ninite](https://ninite.com/) - Installs or updates many common Windows applications at once in one run.
- [Rufus](https://rufus.ie/pl) - Utility for creating bootable USB drives on Windows.
- [single_file_libs](https://github.com/nothings/single_file_libs) - List of single-file C and C++ libraries with clause-less licenses.
- [Ventoy](https://www.ventoy.net/) - Open-source tool to create bootable USB drives from multiple ISO files.
- [HandheldCompanion](https://github.com/Valkirie/HandheldCompanion/releases) - Touch-optimized GUI to improve the experience on handheld gaming PCs.
- [Shadowmap](https://shadowmap.org/) - 3D map for visualizing sunlight, shadows and sun paths for any location.
- [Unicode Text Converter](https://qaz.wtf/u/convert.cgi) - Online tool that converts plain text into Unicode styled text variants.

## Hardware

- [comma.ai](http://comma.ai/) - Company behind openpilot, open-source driver assistance software for supported cars.
- [ESP32-DIV](https://github.com/cifertech/ESP32-DIV) - Multi-purpose wireless toolkit on ESP32 for offensive and defensive security testing.
- [Majsterkowo.pl](http://majsterkowo.pl/) - Polish DIY community sharing projects in electronics, 3D printing, woodworking and cars.
- [Open Source Ecology](https://github.com/OpenSourceEcology) - GitHub organization of Open Source Ecology, which designs open-source industrial machines.
- [PLFM_RADAR](https://github.com/NawfalMotii79/PLFM_RADAR) - Open-source, low-cost 10.5 GHz phased array radar system.

## Audio and DSP

- [musicdsp.org](http://musicdsp.org/) - Archive of audio DSP code snippets and algorithms.
- [Gamma](https://github.com/LancePutnam/Gamma) - C++ library for generic sound synthesis.
- [Introduction to Computer Music (PDF)](https://composerprogrammer.com/introductiontocomputermusic.pdf) - PDF on computer music, hosted on composerprogrammer.com.
- [Making Audio Plugins](http://martin-finke.de/blog/tags/making_audio_plugins.html) - Blog series on writing audio plugins, by Martin Finke.

## Privacy

- [Niepodam.pl](https://niepodam.pl/) - Disposable email service for signing up to sites without exposing a private address.
- [Redact](https://redact.dev/) - Tool for mass-deleting social media posts and opting out of data brokers.
- [Termly](https://termly.io/) - Privacy compliance platform for generating policies and managing consent on websites.
- [Tuta](https://tutanota.com/pl) - Encrypted email, calendar and contacts service with a free tier.
