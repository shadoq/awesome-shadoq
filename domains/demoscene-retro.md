# Demoscene and retro computing

[Back to the index](../README.md)

## In short

The demoscene is the art of pushing fixed hardware past what it was designed for, and retro computing keeps that hardware and its software alive. Many graphics and compression tricks used today were first shown here.

- **Read the source.** Second Reality's released source, Mark Moxon's annotated Elite disassemblies and Hugi magazine's coding articles teach more about tight code than most courses.
- **Commodore 64 is the most alive platform:** C64-Wiki and the memory map for reference, Kick Assembler with c64lib or the oscar64 C compiler for new code, Kodiak64 for VIC-II tricks, C64.CH and Lemon64 for the scene and games.
- **Amiga:** WHDLoad runs the classics from hard disk; Codetapper's interviews document how the games were made; the Polish Amiga Floppy Preservation Group rescues disks before they rot.
- **Size-coding lives on:** Crinkler for 4k intros, Dwitter and JS1k for tiny visual programs.
- **Archives matter:** Classic Computer Magazine Archive, AtariArchives, 16colo.rs for ANSI art, and Polish sources such as the BIT disk image archive.
- **Sound:** tracker formats (micromod), C64 game music sources and Yamaha synth history connect chiptune with FM synthesis.

**Where to start:** awesome-demoscene for the map, C64-Wiki, then pick one effect from the Pouet thread of oldschool effects and code it.
