# Contributing

Suggestions are welcome through an issue or a pull request.

- Edit the page of the field directly (`domains/*.md`), in the right section, best first.
- One line per link: `- [Name](url) - One sentence description.`
- Link the project or reference itself, not a search result, a shortened URL or a page behind a login.
- Use `https://` when the site supports it.
- Mark only essential references with ⭐.
- Update the link count of the field in `README.md`.

`scripts/check_links.py` checks every link on the field pages and runs monthly through GitHub Actions. Links that stop answering are removed.
