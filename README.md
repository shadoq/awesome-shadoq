# Awesome shadoq [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated, link-checked map of the tools and references a software developer actually kept over many years: AI coding agents and local LLMs, generative media, web development, graphics and the demoscene, small-business building, and more.

This list started as about 2,900 browser bookmarks collected since the early Android and PHP days and grew through the current wave of AI coding agents. Each field page opens with a short distillation, which says what matters in that field and how to read the links, followed by the links grouped by topic.

## How the list was built

1. The bookmark export was parsed, deduplicated.
2. A script requested every remaining address and dropped the ones that no longer answer, return 404, or now host a parked domain or spam.
3. AI agents reviewed every surviving link for lasting value, assigned it to a field and wrote a one-line description. Links scored 3 to 5 out of 5 made the cut, and the essential ones are marked ⭐.
4. Each field page got a short summary written on top of the curated list.

1010 links survived out of about 2,900 bookmarks. Projects by the author of this list are marked as such.
